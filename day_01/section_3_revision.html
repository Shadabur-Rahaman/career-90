01 Numbers

Python has two number types you'll use constantly: int (whole numbers) and float (numbers with a decimal point). You do maths on them with operators — symbols like + that combine two values into one result.

The five operators that matter

+ add, - subtract, * multiply — exactly like a calculator. The three that actually confuse beginners:

  • / — "true division". Always returns a float, even when the answer is a whole number. 4 / 2 gives 2.0, not 2.
  • // — "floor division". Does the division, then throws away everything after the decimal point. 17 // 3 is 5 (not 5.67, just 5).
  • % — "modulo". Gives you the leftover after floor division. 17 % 3 is 2, because 3 goes into 17 five times (15), leaving 2.

** is power: 2 ** 7 means 2 to the power of 7 = 128.

02 Strings

A string is just text, wrapped in quotes — 'like this' or "like this", both identical. The one thing worth real attention here is indexing and slicing: how you pull characters out of a string.

The fencepost model

Don't think of index numbers as sitting on a letter. Think of them as sitting between letters, like fence posts. Position 0 is the fence before the first letter, position 6 is the fence after the last letter (for a 6-letter word). A slice word[i:j] grabs everything between fence i and fence j.

Negative numbers count from the right fence backwards: -1 is one fence in from the end.

03 Lists

A list is a container: [1, 4, 9, 16, 25]. Same indexing and slicing rules as strings — but lists are mutable, meaning you can change them after creating them. This one fact causes more bugs than anything else in beginner Python, so it earns the most attention here.

The reference trap — watch closely

rgba = rgb does not make a new list. It just gives a second name to the same list. Click append and watch both names update.

rgb ↘ ["Red", "Green", "Blue"] ↙ rgba

Both boxes are empty until you click append — they're literally the same object.

The fix — a real copy

correct_rgba = rgba[:] builds a brand-new list. Now they're independent.

rgba → ["Red","Green","Blue","Alph"]
correct_rgba → ["Red","Green","Blue","Alph"]

Edit the copy — the original stays untouched.

Nested lists

A list can hold other lists. x[0] gets the first inner list; x[0][1] digs one level deeper to get its second item.

x[0] → ['a','b','c']
x[0][1] → 'b'
x[1] → [1,2,3]
code
squares = [1, 4, 9, 16, 25]
squares[-1]          # 25
squares.append(36)   # lists ARE mutable — this edits in place

rgb = ["Red", "Green", "Blue"]
rgba = rgb            # NOT a copy — same object, two names
rgba.append("Alph")
rgb                   # ["Red", "Green", "Blue", "Alph"]  ← changed too!

correct_rgba = rgba[:]        # a real, independent copy
correct_rgba[-1] = "Alpha"    # only affects correct_rgba

x = [['a','b','c'], [1,2,3]]
x[0][1]   # 'b'

04 Your First Program

Section 3 ends by writing an actual program: printing Fibonacci numbers under 10. Two ideas make this work — multiple assignment and the while loop.

Multiple assignment — no temp variable needed

a, b = b, a + b looks like it should break (doesn't a change before you compute the new b?). It doesn't, because Python evaluates the entire right-hand side first, using the old values — then assigns both at once.

Step through the Fibonacci loop yourself

while a < 10:
