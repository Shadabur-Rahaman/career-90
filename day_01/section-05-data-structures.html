SECTION 05 · PYTHON DATA STRUCTURES · §5.1 – §5.8

Four containers.
Three questions.

Lists, tuples, sets and dictionaries are usually taught as four vocabularies to memorise. They are better understood as four answers to the same three questions — and every method in this section falls out of the answers. Set the switches and watch which container you just described.

Below, each idea gets a bench. Programs on a bench really execute: the trace is generated by evaluating the source, the state panels are the actual state, and every counter is measured rather than asserted. Step forwards, step backwards, edit the code, break it on purpose. ← → step · space run · R reset.
